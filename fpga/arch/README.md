# FPGA Architecture Database for nextpnr-xilinx

This directory contains the chip architecture description files for
nextpnr-xilinx, sourced from [Project X-Ray](https://github.com/Xilinx/prjxray).

## Generated `chipdb.bin`

`chipdb.bin` (57 MB) — the compiled binary database for XC7Z010CLG400-1.
It was generated by:

```bash
# 1. Export BBA assembly from prjxray-db + nextpnr-meta
python3 xilinx/python/bbaexport.py \
  --xray <prjxray-db>/zynq7 \
  --metadata <nextpnr-xilinx-meta>/zynq7 \
  --device xc7z010clg400-1 \
  --constids <nextpnr-src>/xilinx/constids.inc \
  --bba xc7z010clg400-1.bba

# 2. Assemble to binary chipdb
bba --le xc7z010clg400-1.bba chipdb.bin
```

Source files in this directory (`part.yaml`, `part.json`, `package_pins.csv`,
`required_features.fasm`) come from prjxray-db and nextpnr-xilinx-meta,
and are used by the export tool above.

## Regenerating chipdb.bin

If you rebuild nextpnr-xilinx or update prjxray-db:

```bash
# Regenerate .bba from prjxray sources
python3 bbaexport.py --xray ../prjxray-db/zynq7 \
  --metadata ../nextpnr-xilinx-meta/zynq7 \
  --device xc7z010clg400-1 \
  --constids ../constids.inc \
  --bba xc7z010clg400-1.bba

# Assemble to binary
bba --le xc7z010clg400-1.bba chipdb.bin
```

`xc7z010clg400-1.bba` (the source assembly, ~163 MB) is not tracked in git.
`chipdb.bin` (the binary, ~57 MB) is tracked.
